# Database Management System DBSYS

Whether you are checking your bank balance or liking a post on social media, you are relying on databases, the invisible backbone of the modern digital world.

## What is a Database?

A database is a large, integrated collection of data. It models a real world enterprise like students at school for example. 

**What is DBMS (database management system)?** 

To manage this huge collection of data, DBMS is a piece of software designed to store and manage databases. It provides for user the capacity to handle and link data among them. 

**What is a Data Model?** 

A data model is a tool for describing data. The relational model of data, typically a table with rows and columns is the the most widely used way to store data with relation between them. This concept is called a relation. Every relation has a schema, which is a description of a particular collection, using a given data model. A schema describes columns and fields.  

A database contains different level of abstraction from the **physical** level which describes the files and indexes used, the **conceptual** schema which defines logical structure and **views which describe how users see the data.**

## How to design a database?

### Database design

Developing a database requires at first to look at the information system development process. An information system part scans:

- the data to be accessed
- the DBMS software
- computer hardware and storage media
- users querying and managing the data
- applications that access and update data

As part of the design of a database, the user has to think about the purpose of its database. Information system process helps to determine the better structure and organization for its creation. 

They have some points to consider before designing a database. The two golden rules are: 

- Duplicate information is bad
- ensuring data integrity and accuracy

Experience shows that database design must never be neglected. Over the past decade, evolving GDPR regulations have forced companies to continuously redesign their databases.

#### Requirements analysis

- What is going to be stored? (data driven)
- How is it going to be used? (process driven)
- Who should access the data?

### How to create a table using SQL commands?

#### **SQL CREATE TABLE**

The CREATE TABLE command allows you to create a table in SQL. Creating a table serves to define the columns and the data types that will be contained in each column (integer, string, date, binary value, etc.).

```sql
CREATE TABLE table_name
(
    column1 data_type,
    column2 data_type,
    column3 data_type,
    column4 data_type
)
```

In this query, four columns have been defined. The keyword "data_type" should be replaced with a keyword to define the data type (INT, DATE, TEXT, etc.). For each column, it is also possible to define options such as (non-exhaustive list):

- **NOT NULL** prevents a null value from being recorded for a column.
- **DEFAULT** assigns a default value if no data is specified for this column when adding a row to the table.
- **PRIMARY KEY** indicates whether this column is considered a primary key for an index.
