# Cloud

## What is the Cloud?

Cloud computing is a way of using IT. It provides customers to get computing ressources over the internet from anywhere. Ressources are on-demand, the provider allocates them to users. They are also flexible, which means that users can add and remove as they want. Customers pay only what they use or reserve what they will use. 

#### Why is the cloud model compelling nowadays?

Cloud model was transforming into virtualized space and nowadays into container-based architecture. User can rent this space instead of investing in data center real estate. Cloud computing has evolved to giving place for infrastructure management and services management

Cloud provides two new types of offering: 

- **IaaS** which is infrastructure as a service. It offers raw compute, storage and network capabilities
- **Paas** which is platform as a service. It offerings bind code to libraries that provide access to the infrastructure application needs

Cloud is the current place where SaaS (software as a service) are located. SaaS provides the entire application stack, delivering an entire cloud based application that customer can access and use. 

### Cloud network

Cloud networking is the set of **networking concepts, tools, and architectures** that allow cloud resources to communicate securely and efficiently.

It is built to give the highest possible throughput with the lowest possible latencies, by leveraging more than 100 caching nodes worldwide. The principle is that high demand content is cached for quicker access. Cloud infrastructures are located all around the world and are divided into sub-regions to facilitate provided services and access management and where services are deployed.  

### Security

Security goes to physical security of data-centers into security of hardware and software of applications. 

At the hardware level, security is divided into 3 different features. 

- The first is **hardware design and provenance**, which refers to how the physical hardware is built, sourced, verified, and managed inside cloud data centers.
- The next feature is a **secure boot stack**, which is a chain of security mechanisms that ensures a machine (physical or virtual) boots using trusted, verified, untampered software.
- The last feature are premises security. It refers to all the physical and environmental protections applied to data centers, server rooms, and hardware facilities where cloud infrastructure physically exists.

Next, at the service deployment layer, where the key feature is the encryption of inter-service communication. It ensures that all traffic between cloud services is secure, authenticated, and protected. It is implemented using: TLS, mTLS, service mesh encryption, private networking + encryption and it protects model inference, embeddings, internal APIs, databases, microservices. 

Then, they have the user identity layer. This layer protects both human users and machine identities by using authentication (AuthN), authorization (AuthZ) and identity governance (IdP) services. It ensures and manages: who the user is? how the user proves their identity? what the user is allowed to do? how access is controlled and moniored?
